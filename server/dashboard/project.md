# Information about the webapp
## Name
The webapp is called SECRAG, with SEC standing for Securities and Exchange Comission, and RAG standing for Retrieval Augmented Generation.

## Functionality
The goal of the webapp is to make fundamental analysis of US listed companies easier and faster.

The user can:
- Talk about any information found in SEC filings with the assistant in regards to a company specified by the user.
- Receive notifications from the assistant once relevant information about the company of his interest is published on the SEC.

## Pricing
The webapp is subscription based.
Cost of subscription is $10 per month or $100 per year.
It is possible to unsubscribe at any moment. 
If the user unsubscribes, he will still have access to the product for the remainder of the billing period, but he will not be refunded.

## About the creators

To contact the creators the user can send an email to contact@secrag.com, or directly through LinkedIn.

## UX / UI
The webapp has a chat interface, where the user is able to converse with the assistant. 
It has no buttons, only a text input field.

The user can make following changes by asking the assistant:
- Sign Up
- Sign In
- Reset Password
- Sign Out
- Change Name
- Change Email

The assistant will understand the intention of the user, and adjust the frontend and backend accordingly.
