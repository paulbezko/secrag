# Project 1 

## Overview
We want to create a service that would be an overpowered toolbox for public company investors and spark curiousity in those who want to learn arts of company analysis.

## Concept

The final product is a subscription-based web service that provides clients with a dashboard consisting of chat area, visuals such as data charts.

The core technology of the product is a Large Language Model (LLM) optimized for working with SEC company filings. 

### Chat
The user will be able to have a conversation with an LLM on a chosen SEC filing. 

Chat memory will be preserved and recycled throughout the conversation.

The user will be able to maintain X number of chats depending on his subscription tier.

LLM will have access to X amount of most recent messages from a particular chat.

The user will be able to easily click on identified complex terms from LLM answers to ask about the definition of selected terms.

#### Prompt templates
The user will have access to various prompt templates which will include useful questions regarding company analysis. The questions include but not limited to:
1. What are the company risk factors?
2. What are the company's products?

We plan to consult with professionals in the field regarding other useful metrics that were missed in the list above. 

The access to certain prompt templates might depend on user's subscription tier.

In addition, user will be able to ask LLM about the meaning of certain terms from prompt templates.

### Visuals

In addition to chat, the dashboard will load and display essential statistics relevant to a chosen filing. The examples include but not limited to:
1. Market segmentation by sector
2. Market segmentation by country
3. Corporate budget

We plan to consult with professionals in the field regarding other useful metrics that were missed in the list above. 

The access to certain metrics may depend user's subscription tier.

## Marketing model
The service will be available via recurring subscription. There will be various subscription levels varying in price. The following features will be limited depending on subscription level:
1. Maximum number of chats
2. Maximum number of messages loaded into LLM memory
3. Access to certain prompt templates
